# Plz-Job 프론트엔드 개발 가이드 — 화면 단위로 만들고 브라우저로 즉시 검증

## Context

`docs/plz_job_requirements.md`와 `docs/API_명세서.md`(v2.0)를 바탕으로, **화면 하나씩 완성하면서 브라우저로 즉시 검증**하는 방식(수직 슬라이스)으로 프론트엔드를 개발한다. 본 문서는 **MVP 범위 전체**를 클론 코딩으로 따라 만들 수 있도록 전체 코드와 "왜 이렇게 하는가"를 함께 담는다.

- 스택: **React + JavaScript / Vite / React Router / TanStack Query / Axios / Recharts**
- 인증: 백엔드가 **HttpOnly·Secure·SameSite 쿠키**로 JWT를 내려준다 → 프론트는 토큰을 직접 읽지 않고 **쿠키 자동 전송(`withCredentials`)** 에 의존한다. "로그인 상태"는 `GET /users/me` 성공 여부로 판단한다.
- 응답 형식: 모든 API는 `{ success, data, error, timestamp }` 봉투 → axios 인터셉터에서 **자동으로 `data`만 벗겨** 반환하고, 실패면 `ApiError(code, message)`로 변환한다.
- 데이터 격리(AUTH-06): 화면은 항상 "내 데이터"만 다룬다. 남의 리소스 접근은 백엔드가 403/404로 막으므로, 프론트는 그 오류를 자연스러운 안내로 표시한다.
- 분석: 차트는 백엔드 집계 API(`/dashboard/*`, `/market/*`)를 **조회만** 한다. 수치 계산은 백엔드/Python이 한다(§12.5). 차트마다 **기준일(dataBaseDate)·표본 수**를 표시하고, 데이터 부족과 오류를 **구분**한다(DASH-09, §12.4).

> 화면·필드·에러코드는 항상 `docs/API_명세서.md`(Base `/api`, 봉투 `{success,data,error,timestamp}`)와 일치시킨다.

## 개발 흐름

> 🤔 **수직 슬라이스(Vertical Slice)가 프론트에선 뭔가요?**
> "API 함수 전부 → 컴포넌트 전부 → 페이지 전부" 처럼 층별로 만들면 마지막에 화면을 붙이기 전까지 아무것도 못 본다. 대신 **화면 하나를 API 함수→React Query 훅→컴포넌트→라우트까지 세로로 관통**해 완성하고 바로 브라우저로 검증한다. 동작하는 화면을 한 걸음씩 확인하며 나아간다.

```
Phase 0: 프로젝트 셋업 + 공통 기반(axios·QueryClient·라우터·레이아웃) → 빈 화면 렌더 확인
   ↓
Phase 1: 소셜 로그인 + 콜백 + 라우트 보호 + 프로필 (AUTH / UI-01·UI-10) → 로그인 검증
   ↓
Phase 2: 공고 등록 — URL 미리보기 + 수동 보정 (JOB-01~04 / UI-04)        → 등록 검증
   ↓
Phase 3: 공고 목록 + 상세 + 단계 변경·이력 (JOB-05·06·07 / UI-03·UI-05)  → CRUD 검증
   ↓
Phase 4: 서류 관리 — 문서·버전 업로드/다운로드/연결 (DOC / UI-06)        → 업로드 검증
   ↓
Phase 5: 전형 일정 + 회고 (PROC / UI-08·UI-09)                          → 일정/회고 검증
   ↓
Phase 6: AI 면접질문 + 리포트 (AI / UI-07)                              → 로딩/오류 검증
   ↓
Phase 7: 대시보드(개인) 차트 (DASH-01·02·03 / UI-02)                    → 차트/필터 검증
   ↓
Phase 8: 시장 분석 + 개인 vs 시장 + AI 리포트 패널 (DASH-04·05·06 / UI-02) → 통합 검증
```

```jsx
const queryClient = new QueryClient({
  defaultOptions: {
    queries: { retry: 1, refetchOnWindowFocus: false, staleTime: 30_000 },
  },
});

ReactDOM.createRoot(document.getElementById("root")).render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <BrowserRouter>
        <App />
      </BrowserRouter>
    </QueryClientProvider>
  </React.StrictMode>,
);
```

## src/api/client.js

> 🤔 **이 파일이 프론트 인증의 핵심이다.**
> ① `withCredentials: true` — 브라우저가 HttpOnly 쿠키를 자동으로 싣게 한다(토큰을 JS로 못 읽으니 이게 유일한 인증 통로).
> ② **응답 봉투 언랩** — 성공이면 `data`만 돌려주고, 실패면 `ApiError(code,message)`로 던진다. 그래서 각 페이지는 `error.message`만 보여주면 된다(백엔드가 한글 메시지를 준다).
> ③ **401 → `/auth/reissue` 1회 자동 재시도** — access 토큰이 만료돼도 사용자가 모르게 갱신한다(AUTH-03). 재발급도 실패하면 로그인 페이지로 보낸다.

```js
import axios from "axios";

export class ApiError extends Error {
  constructor(code, message, status) {
    super(message || "요청을 처리하지 못했습니다.");
    this.code = code;
    this.status = status;
  }
}

export const client = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL, // http://localhost:8080/api
  withCredentials: true, // ★ 쿠키 자동 전송
  timeout: 10_000,
});

// ── 성공: 봉투에서 data만 벗겨 반환 (파일 다운로드(blob)는 그대로) ──
client.interceptors.response.use(
  (res) => {
    if (res.config.responseType === "blob") return res;
    const body = res.data;
    if (body && typeof body === "object" && "success" in body) {
      if (body.success) return body.data;
      throw new ApiError(body.error?.code, body.error?.message, res.status);
    }
    return body;
  },
  async (error) => {
    const original = error.config || {};
    const status = error.response?.status;
    const envelope = error.response?.data;

    // 401 → refresh 쿠키로 1회 재발급 후 원요청 재시도
    const isAuthCall = (original.url || "").includes("/auth/");
    if (status === 401 && !original._retry && !isAuthCall) {
      original._retry = true;
      try {
        await client.post("/auth/reissue"); // 새 토큰 쿠키 재설정
        return client(original); // 원래 요청 재시도
      } catch {
        redirectToLogin();
        return Promise.reject(
          new ApiError("UNAUTHORIZED", "다시 로그인해 주세요.", 401),
        );
      }
    }
    if (status === 401 && isAuthCall) redirectToLogin();

    // 봉투형 에러 → ApiError 로 통일
    if (envelope && typeof envelope === "object" && "error" in envelope) {
      return Promise.reject(
        new ApiError(envelope.error?.code, envelope.error?.message, status),
      );
    }
    return Promise.reject(
      new ApiError("NETWORK_ERROR", "서버에 연결할 수 없습니다.", status),
    );
  },
);

function redirectToLogin() {
  if (window.location.pathname !== "/login") window.location.replace("/login");
}
```

```jsx
// src/components/common/Toast.jsx — 저장/삭제/오류 알림(§12.4 진행 상태 표시)
import { createContext, useCallback, useContext, useState } from "react";
const ToastCtx = createContext(null);
export function ToastProvider({ children }) {
  const [toasts, setToasts] = useState([]);
  const show = useCallback((message, type = "info") => {
    const id = Date.now() + Math.random();
    setToasts((t) => [...t, { id, message, type }]);
    setTimeout(() => setToasts((t) => t.filter((x) => x.id !== id)), 3000);
  }, []);
  return (
    <ToastCtx.Provider value={{ show }}>
      {children}
      <div className="toast-wrap">
        {toasts.map((t) => (
          <div key={t.id} className={`toast toast--${t.type}`}>
            {t.message}
          </div>
        ))}
      </div>
    </ToastCtx.Provider>
  );
}
export const useToast = () => useContext(ToastCtx);
```

# Phase 1 — 소셜 로그인 + 콜백 + 라우트 보호 + 프로필 (AUTH / UI-01·UI-10)

> **사용 API**: `GET /auth/oauth2/{provider}`, `GET /auth/oauth2/{provider}/callback?code=`, `POST /auth/logout`, `GET /users/me`, `PUT /users/me/profile`
> 자체 가입 없이 카카오·구글만. 토큰은 쿠키로 들어오므로 프론트는 **인가 URL로 보내고 → 콜백에서 code 교환만** 하면 된다.

## src/api/auth.js

```js
import { client } from "./client";

export const authApi = {
  getAuthUrl: (provider) =>
    client.get(`/auth/oauth2/${provider}`, {
      params: { redirectUri: redirectUri(provider) },
    }),
  callback: (provider, code) =>
    client.get(`/auth/oauth2/${provider}/callback`, { params: { code } }), // → { user, isNewUser }
  logout: () => client.post("/auth/logout"),
  getMe: () => client.get("/users/me"),
  updateProfile: (body) => client.put("/users/me/profile", body),
};

// 백엔드에 등록된 Redirect URI와 동일해야 한다
function redirectUri(provider) {
  return `${window.location.origin}/auth/callback/${provider}`;
}
```

## src/hooks/useAuth.js

> 🤔 **로그인 상태를 별도 전역 상태로 두지 않는다.** 진짜 인증 여부는 서버 쿠키가 갖고 있으니, 프론트는 `GET /users/me`를 React Query로 한 번 물어보면 그게 곧 "로그인 상태"다. 성공=로그인, 실패(401)=비로그인. 캐시되어 페이지마다 다시 부르지 않는다.

```js
import { useQuery } from "@tanstack/react-query";
import { authApi } from "../api/auth";

export function useAuth() {
  const query = useQuery({
    queryKey: ["me"],
    queryFn: authApi.getMe,
    retry: false, // 401이면 즉시 비로그인 처리
    staleTime: 5 * 60_000,
  });
  return {
    me: query.data,
    isLoggedIn: query.isSuccess,
    isLoading: query.isLoading,
    query,
  };
}
```

## src/pages/LoginPage.jsx (UI-01)

> 🤔 **버튼은 "인가 URL을 받아 그 주소로 이동"만 한다.** 우리 서버가 provider별 인가 URL을 만들어 주므로(`GET /auth/oauth2/{provider}`), 프론트는 받은 `authorizationUrl`로 `window.location`을 옮기면 된다. 동의 후 provider가 우리 콜백 라우트로 `code`와 함께 돌려보낸다.

```jsx
import { useState } from "react";
import { Navigate } from "react-router-dom";
import { authApi } from "../api/auth";
import { useAuth } from "../hooks/useAuth";

export default function LoginPage() {
  const { isLoggedIn, isLoading } = useAuth();
  const [busy, setBusy] = useState(false);

  if (isLoading) return null;
  if (isLoggedIn) return <Navigate to="/" replace />;

  const start = async (provider) => {
    setBusy(true);
    try {
      const { authorizationUrl } = await authApi.getAuthUrl(provider);
      window.location.href = authorizationUrl; // provider 동의 화면으로 이동
    } catch (e) {
      alert(e.message);
      setBusy(false);
    }
  };

  return (
    <div className="login">
      <h1>Plz-Job</h1>
      <p>개발자 취업 준비를 한곳에서 — 공고·서류·일정·회고·시장 분석</p>
      <button disabled={busy} onClick={() => start("kakao")}>
        카카오로 시작하기
      </button>
      <button disabled={busy} onClick={() => start("google")}>
        구글로 시작하기
      </button>
    </div>
  );
}
```

## src/pages/AuthCallbackPage.jsx

> 🤔 **콜백 라우트가 `code`를 토큰 쿠키로 교환한다.** provider는 `http://localhost:5173/auth/callback/kakao?code=...`로 돌아온다. 여기서 `GET /auth/oauth2/kakao/callback?code=...`를 호출하면 백엔드가 **Set-Cookie**로 토큰을 심어준다. 그다음 `me` 캐시를 무효화해 로그인 상태로 만들고 대시보드로 보낸다. (StrictMode가 effect를 2번 호출할 수 있으니 `ref`로 1회만 교환한다.)

```jsx
import { useEffect, useRef, useState } from "react";
import { useNavigate, useParams, useSearchParams } from "react-router-dom";
import { useQueryClient } from "@tanstack/react-query";
import { authApi } from "../api/auth";

export default function AuthCallbackPage() {
  const { provider } = useParams();
  const [params] = useSearchParams();
  const navigate = useNavigate();
  const qc = useQueryClient();
  const [error, setError] = useState(null);
  const done = useRef(false);

  useEffect(() => {
    if (done.current) return;
    done.current = true;
    const code = params.get("code");
    if (!code) {
      setError("인가 코드가 없습니다.");
      return;
    }

    authApi
      .callback(provider, code)
      .then(async () => {
        await qc.invalidateQueries({ queryKey: ["me"] }); // 로그인 상태 갱신
        navigate("/", { replace: true });
      })
      .catch((e) => setError(e.message));
  }, [provider, params, navigate, qc]);

  if (error)
    return (
      <div className="state state--error">
        <p>로그인에 실패했습니다: {error}</p>
        <button onClick={() => navigate("/login", { replace: true })}>
          로그인으로 돌아가기
        </button>
      </div>
    );
  return <div className="state state--loading">로그인 처리 중…</div>;
}
```

## src/pages/ProfilePage.jsx (UI-10, AUTH-05)

```jsx
import { useEffect, useState } from "react";
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { authApi } from "../api/auth";
import { useAuth } from "../hooks/useAuth";
import { useToast } from "../components/common/Toast";

export default function ProfilePage() {
  const { me } = useAuth();
  const qc = useQueryClient();
  const { show } = useToast();
  const [form, setForm] = useState({
    nickname: "",
    desiredPosition: "",
    desiredRegion: "",
    techStacks: "",
  });

  useEffect(() => {
    if (me)
      setForm({
        nickname: me.nickname ?? "",
        desiredPosition: me.desiredPosition ?? "",
        desiredRegion: me.desiredRegion ?? "",
        techStacks: (me.techStacks ?? []).join(", "),
      });
  }, [me]);

  const save = useMutation({
    mutationFn: () =>
      authApi.updateProfile({
        nickname: form.nickname,
        desiredPosition: form.desiredPosition,
        desiredRegion: form.desiredRegion,
        techStacks: form.techStacks
          .split(",")
          .map((s) => s.trim())
          .filter(Boolean),
      }),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ["me"] });
      show("프로필을 저장했습니다.", "success");
    },
    onError: (e) => show(e.message, "error"),
  });

  const on = (k) => (e) => setForm((f) => ({ ...f, [k]: e.target.value }));

  return (
    <div className="card">
      <h2>프로필</h2>
      <label>
        닉네임
        <input value={form.nickname} onChange={on("nickname")} />
      </label>
      <label>
        희망 직무
        <input
          value={form.desiredPosition}
          onChange={on("desiredPosition")}
          placeholder="백엔드"
        />
      </label>
      <label>
        희망 지역
        <input
          value={form.desiredRegion}
          onChange={on("desiredRegion")}
          placeholder="서울"
        />
      </label>
      <label>
        주요 기술 스택(쉼표 구분)
        <input
          value={form.techStacks}
          onChange={on("techStacks")}
          placeholder="Java, Spring, Oracle"
        />
      </label>
      <button disabled={save.isPending} onClick={() => save.mutate()}>
        {save.isPending ? "저장 중…" : "저장"}
      </button>
    </div>
  );
}
```

### 🧪 Phase 1 브라우저 검증

1. **보호 라우트**: 로그아웃 상태로 `/` 접속 → 자동으로 `/login`
2. **로그인**: 카카오/구글 버튼 → 동의 화면 → 콜백 → 대시보드로 복귀, 헤더에 닉네임 표시

5. **로그아웃**: 헤더 로그아웃 → `/login`, 쿠키 만료(Max-Age=0)
6. **토큰 만료 재발급**: (선택) access 만료 시간(30분)을 짧게 줄여 테스트 — 401 발생 시 자동 `/auth/reissue` 후 화면 그대로 동작

## src/pages/JobCreatePage.jsx

> 🤔 **미리보기 → 폼 자동 채움 → 사용자가 보정 → 저장.** 흐름이 끊기지 않게 설계한다.
>
> - `extractStatus`가 `PARTIAL`/`FAILED`거나 SSRF·차단 오류(`URL_NOT_ALLOWED`, `CRAWL_BLOCKED`)가 나도 **폼은 그대로 열어 둔다**(JOB-04). 추출된 값만 채우고 나머지는 직접 입력.
> - 저장 시 `409 DUPLICATE_JOB_URL`이면 "이미 등록한 URL입니다. 그래도 저장할까요?"를 물어 `confirmDuplicate: true`로 재요청한다(JOB-09).

```jsx
import { useState } from "react";
import { useNavigate } from "react-router-dom";
import { useMutation } from "@tanstack/react-query";
import { jobApi } from "../api/jobPostings";
import { STAGE_OPTIONS } from "../constants/enums";
import { useToast } from "../components/common/Toast";

const EMPTY = {
  companyName: "",
  title: "",
  url: "",
  position: "",
  region: "",
  startDate: "",
  deadline: "",
  techStacks: "",
  description: "",
  initialStage: "INTERESTED",
};

export default function JobCreatePage() {
  const navigate = useNavigate();
  const { show } = useToast();
  const [url, setUrl] = useState("");
  const [form, setForm] = useState(EMPTY);
  const [extractInfo, setExtractInfo] = useState(null);

  // ── 미리보기(자동 입력) ──
  const preview = useMutation({
    mutationFn: () => jobApi.preview(url),
    onSuccess: (data) => {
      const ex = data.extracted ?? {};
      setForm((f) => ({
        ...f,
        url: data.sourceUrl ?? url,
        companyName: ex.companyName ?? f.companyName,
        title: ex.title ?? f.title,
        position: ex.position ?? f.position,
        region: ex.region ?? f.region,
        startDate: ex.startDate ?? f.startDate,
        deadline: ex.deadline ?? f.deadline,
        techStacks: ex.techStacks ? ex.techStacks.join(", ") : f.techStacks,
      }));
      setExtractInfo({
        status: data.extractStatus,
        missing: data.missingFields ?? [],
      });
    },
    onError: (e) => {
      // 추출 실패·차단이어도 수동 입력으로 진행(JOB-04)
      setForm((f) => ({ ...f, url }));
      setExtractInfo({ status: "FAILED", missing: [], note: e.message });
      show(`${e.message} 직접 입력으로 등록할 수 있어요.`, "info");
    },
  });

  // ── 저장(중복 확인 포함) ──
  const save = useMutation({
    mutationFn: (confirmDuplicate) =>
      jobApi.create({
        ...form,
        startDate: form.startDate || null,
        deadline: form.deadline || null,
        techStacks: form.techStacks
          .split(",")
          .map((s) => s.trim())
          .filter(Boolean),
        confirmDuplicate,
      }),
    onSuccess: (data) => {
      show("공고를 등록했습니다.", "success");
      navigate(`/jobs/${data.jobPostingId}`);
    },
    onError: (e) => {
      if (e.code === "DUPLICATE_JOB_URL") {
        if (window.confirm("이미 등록한 URL입니다. 그래도 저장할까요?"))
          save.mutate(true);
      } else {
        show(e.message, "error");
      }
    },
  });

  const on = (k) => (e) => setForm((f) => ({ ...f, [k]: e.target.value }));

  return (
    <div className="card">
      <h2>공고 등록</h2>

      <section>
        <label>
          공고 URL
          <input
            value={url}
            onChange={(e) => setUrl(e.target.value)}
            placeholder="https://careers.example.com/jobs/123"
          />
        </label>
        <button
          disabled={!url || preview.isPending}
          onClick={() => preview.mutate()}
        >
          {preview.isPending ? "불러오는 중…" : "자동으로 채우기"}
        </button>
        {extractInfo && (
          <p className="meta">
            추출 상태: {extractInfo.status}
            {extractInfo.missing?.length > 0 &&
              ` · 빈 항목: ${extractInfo.missing.join(", ")} (직접 입력하세요)`}
          </p>
        )}
      </section>

      <form
        onSubmit={(e) => {
          e.preventDefault();
          save.mutate(false);
        }}
      >
        <label>
          회사명 *
          <input
            required
            value={form.companyName}
            onChange={on("companyName")}
          />
        </label>
        <label>
          공고명 *<input required value={form.title} onChange={on("title")} />
        </label>
        <label>
          직무
          <input
            value={form.position}
            onChange={on("position")}
            placeholder="백엔드"
          />
        </label>
        <label>
          지역
          <input
            value={form.region}
            onChange={on("region")}
            placeholder="서울 강남구"
          />
        </label>
        <label>
          시작일
          <input
            type="date"
            value={form.startDate}
            onChange={on("startDate")}
          />
        </label>
        <label>
          마감일
          <input type="date" value={form.deadline} onChange={on("deadline")} />
        </label>
        <label>
          기술 스택(쉼표)
          <input
            value={form.techStacks}
            onChange={on("techStacks")}
            placeholder="Java, Spring Boot"
          />
        </label>
        <label>
          설명
          <textarea
            value={form.description}
            onChange={on("description")}
            rows={4}
          />
        </label>
        <label>
          초기 단계
          <select value={form.initialStage} onChange={on("initialStage")}>
            {STAGE_OPTIONS.map((o) => (
              <option key={o.value} value={o.value}>
                {o.label}
              </option>
            ))}
          </select>
        </label>
        <button type="submit" disabled={save.isPending}>
          {save.isPending ? "저장 중…" : "등록"}
        </button>
      </form>
    </div>
  );
}
```

### 🧪 Phase 2 브라우저 검증

1. **자동 채우기**: 유효 URL 입력 → "자동으로 채우기" → 폼에 회사명/제목 등 채워짐, 추출 상태 표시

4. **중복 URL**: 같은 URL 재등록 → 확인창 → "예" 시 저장(JOB-09)
5. **필수값 누락**: 회사명 비우고 등록 → 브라우저 검증 또는 `422` 메시지

## src/pages/JobListPage.jsx (UI-03)

> 🤔 **필터·페이지를 `queryKey`에 넣으면 React Query가 자동 재조회한다(JOB-05, DASH-08과 같은 패턴).** 상태/회사/직무/기간을 바꿀 때마다 키가 바뀌고, 같은 키는 캐시를 재사용한다. 페이지 응답(`content/totalPages/...`)을 그대로 활용한다.

```jsx
import { useState } from "react";
import { Link } from "react-router-dom";
import { useQuery } from "@tanstack/react-query";
import { jobApi } from "../api/jobPostings";
import { STAGE_OPTIONS, STAGE_LABELS, label } from "../constants/enums";
import Loading from "../components/common/Loading";
```

# Phase 4 — 서류 관리: 문서·버전 업로드/다운로드/연결 (DOC / UI-06)

> **사용 API**: `POST·GET /documents`, `GET /documents/{id}`, `POST /documents/{id}/versions`(multipart), `GET /document-versions/{id}/download`, `DELETE /document-versions/{id}`, `POST /applications/{applicationId}/documents/{versionId}`

## src/api/documents.js

> 🤔 **버전 업로드는 `FormData`로 보낸다(파일 + 메타).** axios가 `multipart/form-data` 경계를 자동 설정하므로 Content-Type을 직접 지정하지 않는다. 다운로드는 봉투가 아니라 **바이너리**라 `responseType: 'blob'`으로 받는다(인터셉터가 blob은 언랩하지 않음).

```js
import { client } from "./client";

export const docApi = {
  create: (body) => client.post("/documents", body),
  list: () => client.get("/documents"),
  detail: (documentId) => client.get(`/documents/${documentId}`),
  uploadVersion: (documentId, { file, versionName, description }) => {
    const fd = new FormData();
    fd.append("file", file);
    fd.append("versionName", versionName);
    if (description) fd.append("description", description);
    return client.post(`/documents/${documentId}/versions`, fd);
  },
  download: (versionId) =>
    client.get(`/document-versions/${versionId}/download`, {
      responseType: "blob",
    }),
  removeVersion: (versionId) =>
    client.delete(`/document-versions/${versionId}`),
  linkToApplication: (applicationId, versionId) =>
    client.post(`/applications/${applicationId}/documents/${versionId}`),
};
```

## src/pages/DocumentsPage.jsx (UI-06)

> 🤔 **업로드 전 클라이언트에서도 형식·용량을 1차 점검한다.** 백엔드가 최종 검증하지만(확장자+MIME+실제형식), PDF/TXT·10MB를 미리 막으면 사용자 경험이 낫다(§12.1, DOC-01). 다운로드는 blob → `URL.createObjectURL` 로 저장한다.

```jsx
import { useState } from "react";
import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query";
import { docApi } from "../api/documents";
import { DOCUMENT_TYPE_LABELS, label } from "../constants/enums";
import Loading from "../components/common/Loading";
import ErrorState from "../components/common/ErrorState";
import EmptyState from "../components/common/EmptyState";
import { useToast } from "../components/common/Toast";

const MAX = 10 * 1024 * 1024;
const ALLOWED = ["application/pdf", "text/plain"];

export default function DocumentsPage() {
  const qc = useQueryClient();
  const { show } = useToast();
  const [selected, setSelected] = useState(null);

  const docs = useQuery({ queryKey: ["documents"], queryFn: docApi.list });
  const detail = useQuery({
    queryKey: ["document", selected],
    queryFn: () => docApi.detail(selected),
    enabled: !!selected,
  });

  const createDoc = useMutation({
    mutationFn: (body) => docApi.create(body),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ["documents"] });
      show("문서를 만들었습니다.", "success");
    },
    onError: (e) => show(e.message, "error"),
  });

  const upload = useMutation({
    mutationFn: ({ file, versionName }) =>
      docApi.uploadVersion(selected, { file, versionName }),
    onSuccess: (v) => {
      qc.invalidateQueries({ queryKey: ["document", selected] });
      show(
        v.extractStatus === "SUCCESS"
          ? "업로드·텍스트 추출 완료"
          : "업로드 완료(텍스트 추출 실패 — 다른 파일/직접 입력)",
        "success",
      );
    },
    onError: (e) => show(e.message, "error"),
  });

  const handleUpload = (e) => {
    e.preventDefault();
    const file = e.target.file.files[0];
    const versionName = e.target.versionName.value;
    if (!file) return;
    if (!ALLOWED.includes(file.type))
      return show("PDF 또는 TXT만 업로드할 수 있어요.", "error");
    if (file.size > MAX) return show("파일은 최대 10MB까지예요.", "error");
    upload.mutate({ file, versionName });
    e.target.reset();
  };

  const download = async (versionId, fileName) => {
    try {
      const res = await docApi.download(versionId); // blob 응답
      const blobUrl = URL.createObjectURL(res.data);
      const a = document.createElement("a");
      a.href = blobUrl;
      a.download = fileName || "document";
      a.click();
      URL.revokeObjectURL(blobUrl);
    } catch (err) {
      show(err.message, "error");
    }
  };

  return (
    <div className="documents">
      <section className="card">
        <h2>내 문서</h2>
        <CreateDocForm
          onCreate={(b) => createDoc.mutate(b)}
          pending={createDoc.isPending}
        />
        {docs.isLoading ? (
          <Loading />
        ) : docs.isError ? (
          <ErrorState error={docs.error} onRetry={docs.refetch} />
        ) : docs.data.length === 0 ? (
          <EmptyState message="문서가 없습니다. 이력서/자소서를 만들어 보세요." />
        ) : (
          <ul className="doc-list">
            {docs.data.map((d) => (
              <li key={d.documentId}>
                <button
                  className="link"
                  onClick={() => setSelected(d.documentId)}
                >
                  [{label(DOCUMENT_TYPE_LABELS, d.documentType)}] {d.title}
                </button>
              </li>
            ))}
          </ul>
        )}
      </section>

      {selected && (
        <section className="card">
          <h3>버전</h3>
          <form onSubmit={handleUpload}>
            <input name="versionName" placeholder="버전명(v1)" required />
            <input name="file" type="file" accept=".pdf,.txt" required />
            <button disabled={upload.isPending}>
              {upload.isPending ? "업로드 중…" : "버전 업로드"}
            </button>
          </form>
          {detail.isLoading ? (
            <Loading />
          ) : (
            <ul className="version-list">
              {detail.data?.versions?.map((v) => (
                <li key={v.versionId}>
                  <b>{v.versionName}</b> · {v.fileName} · 추출{" "}
                  {v.hasExtractedText ? "○" : "✕"}
                  <button onClick={() => download(v.versionId, v.fileName)}>
                    다운로드
                  </button>
                </li>
              ))}
            </ul>
          )}
        </section>
      )}
    </div>
  );
}

function CreateDocForm({ onCreate, pending }) {
  const [documentType, setType] = useState("RESUME");
  const [title, setTitle] = useState("");
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        onCreate({ documentType, title });
        setTitle("");
      }}
    >
      <select value={documentType} onChange={(e) => setType(e.target.value)}>
        {Object.entries(DOCUMENT_TYPE_LABELS).map(([v, l]) => (
          <option key={v} value={v}>
            {l}
          </option>
        ))}
      </select>
      <input
        value={title}
        onChange={(e) => setTitle(e.target.value)}
        placeholder="백엔드 이력서"
        required
      />
      <button disabled={pending}>문서 만들기</button>
    </form>
  );
}
```
